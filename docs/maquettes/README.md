# Maquettes

9 écrans en 1440 × 1024 (`.svg` éditables + `.png` d'aperçu).

**Import dans Figma** : glisser-déposer les `.svg` sur le canevas (ou *File › Import*). Chaque écran arrive comme un groupe de rectangles et de **textes éditables**. Sélectionnez-le puis *Frame selection* (Ctrl/Cmd + Alt + G) pour en faire un frame. Police utilisée : **Overpass** (disponible dans Figma).

| Fichier | Écran | Module |
|---|---|---|
| 01-connexion | Connexion (+ état d'erreur) | Socle |
| 02-accueil | Accueil connecté | Socle |
| 03-recherche-trajets | Recherche filtrée + état vide | B |
| 04-publier-trajet | Formulaire + erreur de validation | A |
| 05-mes-trajets-demandes | Mes trajets + demandes reçues | A |
| 06-mes-reservations | Suivi des demandes | B |
| 07-profil-public | Note moyenne, trajets, avis | B |
| 08-laisser-avis | Notation 1 à 5 + cas bloqués | C |
| 09-admin | Stats globales + modération | C |

Les encadrés jaunes sont des **annotations** (règles métier), pas des éléments de l'interface.

**Charte** : encre `#1C2B33`, fond `#F6F7F4`, vert panneau `#0E7458`, jaune marquage `#F3C318`, rouge `#B8402B`, gris `#DCE2DE`. Police Overpass (dérivée des caractères de la signalisation routière).
